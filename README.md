# साउंड ट्रैकर (SoundTracker)

फोन में टच, स्वाइप, होम, बैक (अनुमानित), रीसेंट्स, ऐप ड्रॉवर, नोटिफिकेशन पैनल आदि पर अलग-अलग साउंड बजाने वाला और हर गतिविधि
(ऐप/स्क्रीन का नाम + क्या हुआ + समय) रिकॉर्ड करने वाला Android ऐप।

## GitHub से APK बनाना
1. GitHub पर नई repository बनाएँ और इस ज़िप की सारी फाइलें (छुपा हुआ `.github` फोल्डर भी) अपलोड करें।
2. `Actions` टैब → `Build APK` चलने दें (या `Run workflow` दबाएँ)।
3. रन पूरा होने पर नीचे `Artifacts` में `SoundTracker-APK` डाउनलोड करें → उसके अंदर `app-debug.apk` है।
4. APK फोन में इंस्टॉल करें → ऐप खोलकर एक्सेसिबिलिटी सेवा चालू करें।

## Android Studio से
प्रोजेक्ट खोलें → Build → Build APK(s)।
